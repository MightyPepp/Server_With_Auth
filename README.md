# Server_With_Auth

## Автоматизация

В текущем виде сервер запускается посредством скрипта startServer.sh, который вызывает existanceCrtsAndKeys.sh, который, в случае отсутствия ключей и сертификатов, генерирует их и собирает бинарь сервера.
